## Cutover

Repo-review shell now admits only pinned, hardened local Git inspection with explicit inspect authority and a bound root. Git mutations, fetch/network operations, all `gh` operations, generic commands, and project-test/declaration overrides are refused with typed-tool migration guidance. Review/remediation uses the existing immutable PR scopes, checkout leases, and typed `pr_*`/`repo_*` tools.

Deleted the legacy mutation/forge target matcher, body capture and argv rewrite, branch/refspec/worktree-write helpers, API/repository binding parser, npm-ci admission, shell checkout-proof adapter and its four call sites, and `mark_checked_out`. Shared GitHub reader tables remain solely for the out-of-scope maintenance/session-boundary profiles, not as a repo-review fallback. Local inspection also closes implicit no-index file reads and neutralizes effective global/included Git filters.
